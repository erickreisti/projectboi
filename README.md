> **Website moderno e responsivo** para a Churrascaria Boi de Ouro, apresentando o autêntico churrasco gaúcho com 25+ anos de tradição.

## ✨ Destaques

- 🎨 **Design Moderno** - Interface elegante e profissional
- 📱 **Totalmente Responsivo** - Adaptável a todos os dispositivos
- ⚡ **Performance Otimizada** - Carregamento rápido e suave
- 🍖 **Cardápio Interativo** - Filtros dinâmicos e animações
- 🎯 **UX/UI Intuitiva** - Navegação simples e agradável

## 🚀 Funcionalidades

### 🏠 Seção Hero
- Design impactante com call-to-action claro
- Estatísticas da empresa em destaque
- Cards flutuantes com pratos principais
- Navegação suave entre seções

### 📋 Cardápio Interativo
- **Filtros por Categoria**: Carnes, Executivos, Combos
- **Cards Animados**: Efeitos hover e transições suaves
- **Busca Inteligente**: Encontre pratos rapidamente
- **Design Responsivo**: Adaptável a todos os tamanhos de tela

### 📞 Sistema de Reservas
- Formulário de reserva online
- Validação em tempo real
- Design intuitivo e amigável
- Confirmação visual

### 📱 Design Responsivo
- **Mobile-First**: Otimizado para dispositivos móveis
- **Tablet**: Layout adaptado para tablets
- **Desktop**: Experiência completa para computadores

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Finalidade |
|------------|------------|
| **HTML5** | Estrutura semântica e acessível |
| **CSS3** | Estilização avançada e animações |
| **JavaScript** | Interatividade e dinamismo |
| **Bootstrap 5** | Framework CSS responsivo |
| **Bootstrap Icons** | Ícones modernos e consistentes |
| **AOS Library** | Animações on-scroll |
| **Google Fonts** | Tipografia profissional |

## 📱 Responsividade

| Dispositivo | Breakpoint | Características |
|-------------|------------|-----------------|
| **Mobile** | < 768px | Menu hamburger, cards em coluna única |
| **Tablet** | 768px - 992px | Cards em 2 colunas, layout otimizado |
| **Desktop** | > 992px | Layout completo, 3 colunas, hover effects |
